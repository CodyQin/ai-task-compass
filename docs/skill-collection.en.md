# One entry point, four independent modules

[Overview](../README.md) · [中文](skill-collection.zh-CN.md) · [Shared brief](../templates/PROJECT-BRIEF.md)

A business and AI-project planning toolkit, from discovery to pilot review. It is not automated due diligence, a deployed business system or a guarantee of startup success.

| Entry/module | Use when | Deliverable |
|---|---|---|
| [task-compass](../skills/task-compass/SKILL.md) | Unsure where to start or coordinating the whole plan | Select the relevant stage and maintain one coherent project brief |
| [business-discovery](../skills/business-discovery/SKILL.md) | Business, venture or creator problem lacks evidence | Problem/user/buyer brief, assumptions and learning experiment |
| [ai-solution-design](../skills/ai-solution-design/SKILL.md) | Need a bounded implementation route | Task-level quadrants, responsibilities, output contract and prerequisites |
| [model-evaluation-plan](../skills/model-evaluation-plan/SKILL.md) | Comparing feasible models or systems | Acceptance, cases, run log and quality-first cost comparison |
| [ai-pilot-review](../skills/ai-pilot-review/SKILL.md) | Planning a trial or reviewing results | Scope/exposure, stops, time/cash accounting and next decision |

Ordinary chat users can use the full prompt; the integrated entry includes stage selection and handoffs. Skip irrelevant stages for small tasks. Skill-capable tools can load any folder independently or all five from `skills/`, following that tool's directory conventions. No multi-agent setup is required.

Owners start with a real recurrent workflow and acceptance owner; PMs define input/output and tests; founders distinguish users, buyers and evidence (synthetic personas are not customer validation); creators separate production assistance from editorial/factual responsibility, audience quality and actual revenue. Not every issue needs AI.

Keep facts, assumptions and corrections in the [same brief](../templates/PROJECT-BRIEF.md), rather than re-interviewing or inventing continuity.

Available now: five skills, bilingual prompts, references, design blueprints/templates, starter-message pages and a local calculator. Not provided: automatic business-data collection, deployed RAG/workflows, executed model rankings or measured gains. Multiple modules do not imply autonomous multi-model execution.
