现有可运行的本地代码是消息生成页面与业务测算器及其构建/检查脚本。Skill 和模板可交给兼容工具使用。RAG、LangChain、LangGraph、Harness、模型 API 等提供的是选择依据、学习入口与验收建议，不把链接当成本仓库实现。

Runnable local utilities are starter-message pages, the business calculator and build/check scripts. Skills and templates are usable planning artifacts. Technical routes supply recommendations, learning resources and acceptance guidance; links are not implementations in this repository.

## 推荐输出统一包含 / Recommendation contract

业务问题 → 所需能力 → 起步路线/升级条件 → 数据/账号/地区/维护前提 → 官方资料 → 最小练习 → 验收/失败/接管 → 下一步。每次最多两条相关路线，缺资料标未知。

Problem → capability → simple route/upgrade trigger → prerequisites → official resource → small exercise → acceptance/failure/intervention → next action. At most two relevant routes; unknowns stay unknown.

不以“覆盖所有技术”作为完成标准。新工具只有在能改变业务方案、验证或维护决定时才纳入；不用机械为每个流行词新增 Skill。

Coverage is organized by business decisions, not every trending tool. Add a technology when it changes design, validation or maintenance; do not create a new skill for each buzzword.
