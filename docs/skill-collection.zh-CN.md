# 一个入口，四个可独立使用的模块

[首页](../README.md) · [English](skill-collection.en.md) · [项目简报模板](../templates/PROJECT-BRIEF.md)

这是业务与 AI 项目规划工具箱，覆盖从问题澄清到试点复盘。它不自动完成企业尽调，也不替用户部署业务系统或保证创业成功。

| 入口/模块 | 什么时候用 | 实际输出 |
|---|---|---|
| [task-compass](../skills/task-compass/SKILL.md) | 不确定从哪里开始，或要串起完整流程 | 判断当前阶段，维护同一份项目简报，按需推进 |
| [business-discovery](../skills/business-discovery/SKILL.md) | 有创业/业务/内容想法，但问题与证据不清楚 | 问题简报、用户/付费者、事实与假设、最小学习实验 |
| [ai-solution-design](../skills/ai-solution-design/SKILL.md) | 问题较清楚，需要判断哪些环节怎样做 | 任务四象限、分工、输出约定、工具路线与前提 |
| [model-evaluation-plan](../skills/model-evaluation-plan/SKILL.md) | 有交付要求，要比较模型或整套方案 | 验收标准、样本与记录表、质量门槛、全成本比较条件 |
| [ai-pilot-review](../skills/ai-pilot-review/SKILL.md) | 想小范围验证，或复盘已有结果 | 范围、投入上限、停止条件、时间/现金口径、继续/调整/停止 |

## 普通聊天最快的用法

用首页的完整提示词即可。统一入口已经包含阶段判断与交付要求，不需要用户手动协调几个 Agent。只做一个小任务时，可以要求简短回答或直接跳到所需阶段。

## 支持 Agent Skills 的工具

将需要的技能文件夹复制到该工具支持的技能目录；想使用整套，可复制 `skills/` 下所有五个文件夹。路径和加载方法以你的工具说明为准。也可只安装一个独立模块，各模块自身包含必要步骤，不强制依赖其他模块或多 Agent。

例如：`使用 business-discovery，用中文帮我梳理这个机会；不要急着推荐工具。` 或 `使用 model-evaluation-plan，根据这份交付要求设计一个小比较。`

## 四类起点，同一套判断

- 老板/团队：从最近一次反复等待、查资料或返工的工作开始；确认负责人、频率和验收。
- 产品经理：从输入、用户交付与验收开始；形成有边界的方案和评测，而不只列功能。
- 创业者：区分用户需要、付费者与需求证据；AI 模拟访谈不算客户验证；先验证影响最大的假设。
- 自媒体/个体业务：拆资料整理、来源核实、内容草稿、校对和发布；可辅助的环节与人的表达、事实责任分别说明。产量或播放量上升不自动等于收入增加。

输出可以接进 [同一份项目简报](../templates/PROJECT-BRIEF.md)，避免每一步从头描述、互相矛盾或丢掉用户纠正。

## 当前交付边界

真实交付：五个 Skill、完整中英文提示词、文档/方案蓝图/模板、可用的消息生成页和本地业务测算器。未交付：自动抓取企业数据、已经部署的 RAG/工作流、运行过的模型横评或真实收益保证。多个规划模块不等于多个模型自动并行执行。
